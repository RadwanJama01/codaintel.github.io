## Offline / wifi tips for Djibouti meetings

1. Arrive early. Hotel and ministry wifi vary.
2. Hotspot first. Phone data often beats meeting-room wifi.
3. Preload the logged-in page if the network allows.
4. Backup: short screen recording of the click path.
5. If audio input fails: paste French sample on Emploi; still show edit, submit, My interviews.
6. If the site is slow: narrate the pipe without rushing: speak, draft, review, submit, audit.
7. Never blame the room. Say: "Network is busy. Here is the same path on a recording."
