## How the salesman uses it

1. Open `en/INDEX.md` and follow Day-0 → meeting → follow-up order.
2. Memorize the 60-second elevator in `en/03-salesman-talk-track.md`.
3. Practice `en/04-demo-cheat-sheet.md` twice on live demos before any meeting.
4. Bring the matching one-pager (Emploi or VoiceDoc). HTML versions print cleanly to PDF from a browser.
5. Close with a **four-week paid pilot**: named sponsor + ten trained users + human review always.
6. Same day: run `en/10-leave-behind-checklist.md` (email + CRM fields).
7. Send `en/07-pilot-mou-template.md` only as a **template for counsel review** (not legal advice).

Each product is a simple website. When someone records, audio goes to our always-on service, which turns speech into form fields. Staff always review and edit before submit or export. Emploi and VoiceDoc share that same setup. Only the forms differ. Demo sites only. Never the service links.
