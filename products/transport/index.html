What it does

Record. Draft. Review. Export.

Transport is the voice layer on a weigh-station intake desk: a spoken contrôle de poids becomes a structured draft an agent can edit. Same documentation pipe as VoiceDoc and Emploi Assist, with a pesage schema. Not a production weigh-station system, and not an official Transport ministry product.

Built for the agent pesage

A staffed weigh check, not a public kiosk. The agent records the dictation and remains responsible for the record.

Drafts stay drafts

Fields fill after structuring. Computed amounts are labelled as unsealed. Nothing is official until a human decides.

Same pipe, pesage schema

VoiceDoc’s loop — voice, transcript, structured draft, human review, export — applied to a contrôle de poids. The schema changes; the review step does not.

Workflow

Voice to a reviewable draft.

The agent stays with the weigh check from the first recording through export. The system drafts fields. It does not seal them, fine anyone, or file an official procès-verbal.

  1. 01 · Record

    The agent records or pastes a pesage dictation in the language spoken at the station.

  2. 02 · AI draft

    The recording is transcribed and mapped onto weigh fields. Computed amende / déchargement stay marked as draft.

  3. 03 · Human review

    Every field is editable. Nothing is complete until an agent has reviewed and signed off.

  4. 04 · Export

    After review: a PDF labelled « Projet — soumis à validation ». A project submitted for validation — not a sealed official.
