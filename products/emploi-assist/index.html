Employment intake · Counsellor tools

Emploi Assist

A counsellor-led voice interview that becomes a structured, reviewable jobseeker profile. Same documentation pipe as VoiceDoc — transcript, fixed fields, human sign-off — with an employment schema instead of a field report. Not a public kiosk, and not a self-serve portal.

Request a briefing Counsellor UI demo coming soon

Counsellor voice intake is live as a backend service at voicedoc-emploi-api.fly.dev — an API for the documentation pipe, not a public counsellor interface. There is no login here.

Overview

Interview, draft, review, export.

A counsellor records the conversation. An AI pipeline transcribes it and fills structured jobseeker fields. The counsellor reviews and edits every field. Nothing is auto-filed. After sign-off, the profile exports as CSV or JSON for downstream systems. The model drafts; the person in the room decides.

Counsellor-led, not a kiosk

Built for a staffed intake conversation. The counsellor conducts the interview, owns the recording, and remains responsible for the record. This is not unattended public self-service.

Same pipe, employment schema

VoiceDoc’s documentation loop — voice, transcript, structured draft, human review — applied to jobseeker fields rather than a field report. The schema changes; the review step does not.

Export after review

Structured CSV and JSON exist only after a person has reviewed the draft. The export is a signed-off profile, not a raw model dump.

Workflow

Five steps. A person stays in the loop.

The counsellor stays with the jobseeker from the first question through export. The system drafts fields. It does not submit them.

01 · Voice interview

The counsellor conducts and records the conversation in the language spoken in the room.

02 · Transcript

The recording is transcribed. The audio is kept so a reviewer can hear what the draft claims.

03 · Structured fields

The transcript is mapped onto a jobseeker schema — skills, experience, languages, availability, and related intake fields.

04 · Human review

Every field is editable. A profile is not complete until a counsellor has reviewed and signed off.

05 · Structured export

After review, the profile exports as CSV or JSON for case systems and downstream matching tools.

Honest stage. The counsellor intake API is live. A public counsellor UI is not. This page describes the workflow. It does not claim a government endorsement, a ministry partnership, or a deployed public service.
